Logging a Session in FSP

The following guide should help instructors to grade lessons correctly in FSP, using the "grade by exception" philosophy. The RAAus syllabus contains many tasks and elements, and grading each of them individually would create too much administrative burden. Instead, we grade by exception.

Why we grade this way

We grade by exception, so that we don't have to tick every box. The point of the session is to track deficiencies and prove they were fixed — so the deficiencies are what we want to make visible. Leaving a task ungraded (NG) is a positive statement that it met the required standard, usually solo standard.

The grading scale

NC
Not Yet Competent

Needs more training, or wasn't covered at all — use the notes to say which.

P
Progressing

Not solo standard yet, but good enough to move on. GCSFT‑specific.

S
Solo Standard

The required standard for most lessons — the lowest passing grade on the scale.

C
Competent

Flight‑test standard. Required before we recommend for test.

NG
Not Graded (default)

The default. Read as "met the required standard" — not "skipped".

Rule 1 — NG means "met standard", not "skipped"

Leave every task that meets the required standard at NG. You only add a grade where there's something to say.

Rule 2 — a task not covered is NC, not NG

Leaving a task ungraded tells the next instructor it was covered and met standard. If you didn't get to it, grade it NC and say why in the notes — don't leave it blank.

Rule 3 — P does not equal S

A progressing grade is not a pass. Every task at P must be revisited and actively marked S before first solo. If pre‑solo prep finishes with anything still at P, the student is not ready for solo.

Rule 4 — the overall lesson grade is the final standard

This removes ambiguity, and signals that a student will need to repeat a lesson or has met solo/competent standard. FSP will not let you set a passing overall grade while any graded task is still below standard.

Logging a Session

  1. Session details Student, course, lesson, start date/time, reservation, instructor, aircraft.
    Choose Continue if you're carrying on an incomplete lesson, or Repeat if it was complete and you're flying it again.
  2. Grade by exception Leave met‑standard tasks at NG; grade the deficiencies (NC/P), tasks not covered (NC), or anything you're confirming to S.
    Session Notes are used to distinguish between not covered and not competent.
  3. Set the overall grade route, hours, and session notes.
  4. Sign and save Use Save Draft if you need to finish later. Records must complete within 3 days. Request PIN from the student if this hasn't been entered already.

Confirming solo standard twice — the course progress page

A session tells you about one flight. To confirm a student has actually met the syllabus's "witnessed on two or more occasions" requirement — go to the student's Course Enrollment (Lesson Tab). It lists every lesson in the course with its most recent grade, dual/solo hours, and a chip for every session ever logged against it.

What your're checking

Most Recent GradeThe last badge should be marked S or better on every lesson — no NC or P sitting as the current status. One S chip in each lesson is the first occasion.

The Stage CheckThe stage check/consolidation lesson combines all previous elements. To pass this lesson the student must, again, demonstrate solo standard in all previous elements. This is the second occasion.

CircuitsFor the circuits phase, the C4 Solo Authorisation stage check outlines all requirements needed.

7

Critical gate — C4 Solo Authorisation

C4 · Solo Authorisation Gate

The final circuit check before first solo. The previous stage check confirmed all upper air work elements are at solo standard twice. This stage check confirms that all required circuit elements are also to the required standard.

What to do

  • Grade every REQUIRED heading explicitly: Radio Competency Before Solo, Two‑Occasion Sign‑Off Confirmation, Solo Crosswind Authority, Pre‑Solo Requirements.
  • Solo Crosswind Authority is conditional — grade S if crosswind was under 5 kt on solo day (no endorsement needed), OR 5–8 kt with S standard on two separate crosswind flights. Grade NC if the endorsement isn't met, or the crosswind exceeds 8 kt.
  • Check the RAAus membership status and medical declaration before grading those REQUIRED tasks S.
  • The instructor completing this stage check signs the student's paper logbook with a note authorising solo.

Practice flight test — P4‑L1, override to C minimum

P4‑L1 · Practice Flight TestC minimum override

Final pre‑test check. In FSP, both the lesson and every task have their minimum passing grade overridden to C — an S grade physically cannot pass this lesson.

What to do

  • The REQUIRED — Administration heading must be graded C if completed (logbook totals, DUAL/PIC time minimums, exams, W&B, RAAus documents) — this gates the test booking itself, not just the flying.
  • Grade each of the 16 flight elements at element level — anything below C becomes the P4‑L2 remediation list.
  • If several elements are clearly below C standard, stop the flight, debrief, and reschedule after targeted remediation rather than pushing through the full sequence.
